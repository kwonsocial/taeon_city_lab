원본 보관 및 사용
1. 이 ZIP을 컴퓨터나 별도 저장장치에 다운로드하고 압축을 풀어 보관하세요.
2. story 폴더 전체를 함께 보관해야 사진과 활동지가 유지됩니다.
3. story/index.html을 더블클릭하면 오프라인으로 소개 페이지를 열 수 있습니다.
   웹앱·개인정보처리방침 등 외부 링크는 인터넷 연결이 필요합니다.
4. 소개 페이지는 GitHub 저장소의 story 폴더에서 관리합니다.
5. ChatGPT 계정 삭제와 별개로 GitHub 계정 및 저장소·Pages를 유지해야 합니다.
6. 도시 설계 연구소의 AI 기능은 별도 Cloudflare 계정과 Worker를 유지해야 합니다.
7. 이 백업은 수업 소개 페이지 전체입니다. 도시 설계 연구소 및 AI 서버 원본은 포함하지 않습니다.

- 노트북에 열어 둘 주소와 즐겨찾기는 위 '수업 소개 페이지'로 변경하세요.
- 수업 소개용 인쇄 QR은 taeon-story-qr.png로 교체하세요.
